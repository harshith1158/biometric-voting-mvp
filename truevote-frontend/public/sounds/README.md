# Sound Files for TRUE VOTE

Add your audio files here:

- **click.mp3** — Button click feedback sound (subtle, 100-200ms)
- **success.mp3** — Success/verification tone (uplifting, 500-800ms)

The sound helper will gracefully handle missing files without breaking the app.

## File Requirements
- Format: MP3
- Sample rate: 44.1kHz or higher
- Bit rate: 128kbps or higher
- Keep file sizes small (<50KB each) for fast loading
